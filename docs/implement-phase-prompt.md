## Decisions already taken (do not re-open; flag if one turns out impossible)

1. Class-curse relevance = trained spells (`Player::HasSpell` on the registry
   entry's `requiresSpell`) plus `GetMostPointsTalentTree()` for spec-gated ones.
2. Swap offers: the discarded slot is chosen by the seed stream and shown in
   the offer; the player does not choose it.
3. Every gauntlet summon gives ×0.5 XP through `OnPlayerGiveXP`; Champions
   give full.
4. The Shade spawns in group dungeons too, never while an encounter is in
   progress, attacks only its owner, can be damaged by anyone.
5. `EndRun` moves out of `OnPlayerJustDied`: mark `pendingDeath`, start a 60 s
   timer; `OnPlayerResurrect` with a bargain charge cancels; `OnPlayerReleasedGhost`
   or the timer ends the run. (Phase 3 uses this; Phase 0 only has to leave
   `EndRun` callable from both places.)
6. Legacy runs migrate in place through `LegacyRoll` at worldserver start.
7. The leaderboard records class curses only as conducts; all affixes go in
   `affixes`.

## Definition of done (plan §1, Phase 0)

in the new columns; a pre-migration character (make one on the dev realm
before you migrate) logs in with the same affixes it had; the addon shows
offers and carried affixes from `GNT` messages; `.gauntlet debug offers 7`
prints a plausible tier-7 offer; the unit tests pass; the worldserver starts
clean with the new SQL applied.
